# Презентация

Слайды собираются скриптом, а не правятся в PowerPoint: так их легко пересобрать, когда
изменятся цифры или скриншоты.

```sh
npm install pptxgenjs          # в любом каталоге вне репозитория
node docs/presentation/build.mjs
```

Скрипт кладёт `docs/РадарВузов-презентация.pptx`. Он берёт скриншоты из
`backend/app/help/images/` — те же, что показывает встроенная справка, — поэтому после
обновления снимков достаточно пересобрать презентацию.

PDF рядом (`docs/РадарВузов-презентация.pdf`) — экспорт того же файла: его удобно открыть
на чужой машине, где нет PowerPoint.

Правки текста делайте в `build.mjs`, а не в готовом `.pptx`: иначе следующая сборка их сотрёт.
Заметки докладчику лежат в самих слайдах (`slide.addNotes`), сценарий показа — в
[`DEMO_SCRIPT.md`](../DEMO_SCRIPT.md).
