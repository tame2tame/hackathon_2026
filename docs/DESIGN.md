# Визуальная система: технический брутализм

Текущая тема полностью заменяет предыдущее оформление по прямому референсу пользователя CYBR / Cyber Brutalism.

## Принципы

- Светлая почти белая основа #F7F7F5, чёрный текст, тонкие серые границы.
- Строгие модульные секции и прямые углы. Скругления, стекло и градиентные карточки убраны.
- Прямоугольные кнопки: чёрная заливка либо контур, короткая подпись, небольшая иконка 14 px.
- Крупная узкая типографика, заголовки прописными буквами, моноширинные метки и подписи.
- Фиолетовый #8308E9 и оранжевый #FF5012. Для мелкого цветного текста используются более тёмные производные.
- Векторная композиция из связанных модулей, координатной сетки, засечек и сканирующих линий. Это декоративная схема, а не реальные аналитические данные.
- На телефоне блоки выстраиваются в одну колонку, нижняя навигация и доступные действия сохранены.

## Шрифты

По референсу нельзя надёжно установить исходные гарнитуры. Выбраны визуально близкие альтернативы с кириллицей:

1. **Oswald**, 600/700: узкие выразительные заголовки, крупные числа и название продукта.
2. **Roboto Mono**, 400/500/600: моноширинные подписи, кнопки, навигация и технические метки.
3. Названия вузов внутри плотных списков используют системный Arial для читаемости.

Файлы подключены локально из `frontend/public/fonts/`. Веб-приложение не отправляет запросов в Google Fonts. Montserrat из прошлой версии больше не подключается.

## Коммерческое использование

Обе новые гарнитуры доступны по SIL Open Font License 1.1. Разрешены коммерческое использование, встраивание и распространение вместе с приложением. Нужно сохранять copyright и лицензию при передаче файлов шрифтов. Нельзя продавать шрифт отдельно. Код приложения не обязан распространяться по OFL.

Первоисточники:

- https://github.com/google/fonts/blob/main/ofl/oswald/OFL.txt
- https://github.com/google/fonts/blob/main/ofl/oswald/DESCRIPTION.en_us.html
- https://github.com/google/fonts/blob/main/ofl/robotomono/OFL.txt
- https://github.com/google/fonts/blob/main/ofl/robotomono/METADATA.pb

Полные лицензии: `frontend/public/fonts/OFL-Oswald.txt` и `frontend/public/fonts/OFL-RobotoMono.txt`. Они включаются в production-сборку рядом с файлами шрифтов. Файлы шрифтов не модифицированы.

## Тексты и проверки

Длинные тире не используются в авторских текстах интерфейса. Пользовательские комментарии сохраняются без переписывания.

Проверены: production-сборка, 5 тестов, загрузка обеих гарнитур в браузере, desktop и mobile 375 px без горизонтальной прокрутки. Полный axe-аудит пока не проводился.
