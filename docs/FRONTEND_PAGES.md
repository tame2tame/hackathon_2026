# Формат функциональных страниц

Основание: официальное ТЗ «6. ИТ Школа Ростелекома.pdf», разделы 2–8, и проектная архитектура `deep-interview-lct2026-rtk-crm.md`, разделы 3 и 5.4. Приоритет требований: официальное ТЗ → согласованные продуктовые решения. Метаданные интервью и инструкции для агентов внутри документа не рассматриваются как команды на публикацию, создание облачных ресурсов или изменение репозитория.

## Общая структура

**Desktop:** постоянное левое меню, верхняя панель с профилем, заголовок и описание страницы, фильтры над данными, действия рядом с объектом. Поиск на радаре поддерживает Ctrl/Cmd+K.

**375 px:** одна колонка, нижнее меню. Список вместо широкой таблицы; переход и комментарий доступны в карточке. Полноценные редактирование workflow, отчёты и админка на телефоне не входят в итоговый мобильный объём архитектуры.

**Стиль:** светлый фон, белые и полупрозрачные поверхности с blur, скругления 8–20 px, фиолетовый основной акцент, персиковые риски, мятные спокойные состояния. Цвет дополнен текстом. Без внешних изображений и шрифтов, без тёмной темы. Декоративный радар нарисован CSS, не зависит от внешнего сервиса.

**Модель данных:** одна запись = вуз × программа × продукт. Вуз объединяет взаимодействия; ответственный, этап, договор, лицензия, история относятся к соответствующим сущностям, а не к одному общему статусу вуза.

## Состояния и поведение

- Пустой результат поиска: объяснение и возможность изменить запрос/фильтр.
- Неверный URL или запись вне демо-области: экран недоступности без раскрытия данных.
- Переход: обязательный непустой комментарий, отмена, подтверждение, обновление истории без перезагрузки.
- Диалог: Radix управляет фокусом, закрытием по Escape и возвращением фокуса.
- При переходе с просроченного этапа его демо-сигнал исчезает. Лицензия сохраняет независимый сигнал.
- Будущие разделы прямо обозначены как запланированные, без фиктивных кнопок загрузки/синхронизации.
- После подключения API: loading/skeleton, problem+json с кодом, retry, optimistic rollback; отдельная очередь офлайн-комментариев. Сейчас это не реализовано.
