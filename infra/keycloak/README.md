# Тема входа «Радар вузов»

Тема `radar` наследует стандартные формы Keycloak 26.3. Меняются только оформление
и русские подписи: вход, обработка ошибок, показ пароля и обязательная смена пароля
остаются штатными. Цвета и шрифт соответствуют `frontend/src/brandbook.css`.
Шрифты скопированы из `frontend/public/fonts`, чтобы вход не зависел от сервиса фронтенда.

## Подключение

В обоих Compose-файлах тема смонтирована в `/opt/keycloak/themes/radar`.
Новый realm автоматически получает тему `radar` и русскую локаль при первом импорте.

При каждом запуске контейнера `start-with-theme.sh` запускает Keycloak и через
штатный Admin CLI применяет к существующему realm только четыре поля:
`loginTheme`, `internationalizationEnabled`, `supportedLocales`, `defaultLocale`.
Пользователи, пароли, клиенты, роли и политики безопасности не импортируются повторно.

Пароль администратора берётся из уже используемой переменной
`KC_BOOTSTRAP_ADMIN_PASSWORD` (в production — `KEYCLOAK_ADMIN_PASSWORD` из `.env`)
и передаётся CLI через окружение. Значение должно соответствовать действующему
администратору: bootstrap-переменная не меняет пароль уже созданного пользователя.
Сессионный файл CLI создаётся с закрытыми правами и удаляется после применения.

Контейнер получает статус `healthy` только после применения темы. Если Keycloak
не готов или авторизация не удалась за 60 попыток, либо обновление realm отклонено,
контейнер завершается с ошибкой. Workflow Deploy ожидает `healthy` и не продолжает
выкатку при ошибке.

Workflow Deploy пересоздаёт контейнер Keycloak, чтобы обновить файлы и сбросить
кэш темы. При ручной выкатке после обновления кода выполните из `infra/`:

```sh
docker compose -f docker-compose.prod.yml --env-file .env up -d --no-deps --force-recreate --wait --wait-timeout 300 keycloak
```

Для Yandex добавьте `-f docker-compose.yandex.yml` перед `--env-file`.
Это кратковременно перезапускает сервис входа; база и действующие сессии сохраняются.
Не удаляйте realm или том базы для повторного импорта.

## Проверка

```sh
python3 -m unittest discover -s infra/keycloak/tests
```

Проверить в браузере на Keycloak 26.3: вход, неверный пароль, переключение видимости
пароля, фокус с клавиатуры, форму смены пароля и экран шириной 375 px.
