# Радар вузов — фронтенд ЛЦТ 2026

Базовый результат на 15.09.2026 для кейса №6 ИТ Школы Ростелекома.

## Запуск

Нужен Node.js 22.12+ (или совместимая версия Node 24).

```bash
cd frontend
npm ci
npm run dev
```

Открыть адрес из терминала (обычно http://127.0.0.1:5173).

```bash
npm test
npm run build
npm run preview
```

## Что готово

- Vite + React + TypeScript, React Router, Tailwind CSS 4.
- Базовый Button в стиле shadcn/ui, Radix Dialog, конфигурация `components.json`.
- Светлая тема: сиреневые, персиковые и мятные акценты, полупрозрачные панели, адаптивность от 375 px.
- Оболочка и маршруты всех разделов; демонстрационная видимость по трём ролям, включая прямые URL.
- Радар: 4 типа сигналов, счётчики, поиск, фильтр приоритета и категории.
- Взаимодействия: список/сетка, поиск, фильтр этапа, карточка, 14 этапов, переход с обязательным комментарием, история.
- Список и обзор вузов, встроенная справка, сброс демо.
- Локальное сохранение переходов. Детерминированные данные с датой среза 15.09.2026.
- Unit-тесты доменной демонстрационной логики и CI сборки/тестов.

## Границы первого дня

Переключатель ролей — демонстрация UI, а не авторизация. Backend, Keycloak, серверные права, MSW, согласованный API-клиент, SSE, загрузка файлов, импорт, настоящий канбан, рейтинг, графики, отчёты и админские операции ещё не реализованы. Запланированные страницы прямо показывают свой статус и будущие функции. TanStack Query провайдер подготовлен для подключения API; запросы пока не выполняются.

В демо нет настоящих персональных данных. Вложения и документы не имитируются как загруженные. Переход в демо проверяет только комментарий; правила обязательных файлов будут приходить с сервера. При обновлении страницы выбранная роль возвращается к КАМу. Изменения данных сохраняются в localStorage текущего origin. Сервер будет проверять доступ независимо от интерфейса.
